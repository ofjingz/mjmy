# 横向漫游检查 · 2026-11-20

本轮按用户反馈调整电脑端探索方向、顶栏融合与背景形状运动。此前纵向电脑布局见 `roam-integration-check.md`，以本记录的新版行为为准。

## 已完成

- 电脑漫游使用固定高度的横向画布，8 个入口随机错落，画布按需增加宽度；主文档不纵向滚动。
- 支持触控板横滑、滚轮、鼠标拖动及左右方向键；漫游区域聚焦时 Home / End 可到达两端。拖动超过阈值后拦截点击，正常点击仍直达模块。
- 手机保留上下滚动及原有错落双路径。切换目录会释放横向模式，恢复页面纵向浏览。
- 顶栏去掉深黑背景横条，改用向下延伸并渐隐的柔和蓝色；照片投射方向随横向视口更新，避免按整个画布中线判断造成边缘裁切。
- 浅色背景形状分为顺逆旋转、左右漂移和上下浮动；使用不同周期和负延迟，保留低透明度及减少动态效果时的静止状态。
- 字体继续复用共享标题与正文变量。窄一些的电脑节点中，英文较长的 vibecoding 标题用 28px，避免末字单独落行；未增加字体家族。
- 切换电脑/手机尺寸时不再播放节点位置过渡，避免两种轴向之间短暂交叠。物件自身的漂浮与运动痕迹保留。

本轮仅修改 `site/hub/index.html`、`hub.js`、`roam.css`；调整前副本在 `_staging/roam-horizontal-20261120/before/`。未部署。
